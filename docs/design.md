# Codex Account Toggle UI / UX

## 컨셉: 조용하고 선명한 계정 스위처

계정 선택이라는 한 가지 행동에 집중하는 macOS 메뉴바 유틸리티. 따뜻한 중성 배경, 얇은 경계선, 절제된 청록색으로 현재 상태와 다음 행동을 빠르게 읽을 수 있게 한다. 사진이나 장식용 일러스트 대신 시스템 아이콘과 이름 첫 글자를 사용한다.

## 기존 화면의 문제와 개선

- 현재 계정이 disabled 버튼으로 표시되어 흐려짐 → 명도 저하 없는 독립 카드와 체크 표시로 강조.
- 시나리오 설정이 계정보다 먼저 보임 → 하단 데모 안내에서 필요할 때만 펼침.
- 모든 계정의 같은 아이콘/색상 → 안정된 계정별 색상과 이름 첫 글자로 구분.
- 이름 변경이 우클릭에 숨겨짐 → 각 계정의 가시적인 더보기 메뉴.
- 성공/오류가 일반 안내와 같은 회색 텍스트 → 상태 아이콘, 문구, 배경 색상을 함께 사용.
- 긴 안내문과 과도한 세로 여백 → 중복 문구를 줄이고 기본 높이를 540pt로 조정.

## 구조와 상호작용 (2026-09-14 컴팩트 개편)

(데모 표시줄) → 현재 계정 → 다른 계정 목록 → 필요한 상태 메시지 → 하단 도구 순서. 헤더, 큰 카드, 데모 안내 영역, 가시적 더보기 버튼은 제거했다. 현재 계정은 이름·요금제·잔여 %와 창 이름·초기화 날짜/시각·남은 시간, 4pt 게이지의 두 줄이다. 이메일은 도움말과 접근성 이름으로만 제공한다. 다른 계정도 두 줄이다. 첫 줄은 이름이 독점하고(잘리지 않도록) 잔여 %만 오른쪽에 두며, 둘째 줄에 요금제 배지와 창 이름·남은 시간을 놓는다. 행을 클릭하면 전환한다. 성공 확인 알림은 표시하지 않고 진행 상태·로그인 진행·복구·오류만 띠로 보여준다. 요금제 배지는 Codex 데스크톱 앱의 표기(Free/Go/Plus/Pro 5x/Pro 20x, 비즈니스·엔터프라이즈·교육 변형)를 따른다. 이름 변경은 각 행의 우클릭 메뉴, 데모 시나리오와 표시 옵션은 톱니바퀴 메뉴에 있다. 전환 중에는 계정 선택과 관리 동작을 잠근다. 실제 전환 경로의 확인 절차는 유지한다.

300pt 폭, 높이는 내용에 맞춰 자동(계정 3개 기준 약 224pt). 12pt 바깥 여백, 2~8pt 간격. 현재 계정명 14pt, 일반 계정명 13pt, 보조 정보 11~11.5pt, 잔여 % 16/14pt rounded, 요금제 배지 9.5pt. 데이터 출처는 %% 앞의 작은 표식(`D` 샘플, `기록` 세션 기록, `~` 오래된 값)과 도움말로 알린다. 계정이 6개를 넘으면 목록만 스크롤한다. 다크 모드는 시스템 외관을 따르며 청록색 밝기를 높인다.

아이콘 버튼에 접근성 이름과 도움말 제공. 상태는 색상에만 의존하지 않고 문구/아이콘 병기. 긴 계정명·이메일은 한 줄 생략하며 현재 계정의 전체 값은 도움말로 확인한다. 계정 수가 많아지면 목록만 스크롤한다.

## 검증 범위

실제 SwiftUI/AppKit 뷰를 가짜 계정으로 오프스크린 렌더링하여 라이트/다크, 오류 안내, 펼친 데모 설정의 레이아웃을 확인한다. 실제 로그인, 계정 전환, Codex 종료 테스트는 금지한다. UI 자동 클릭/VoiceOver 전체 탐색 검증은 아직 수행하지 않았다.

## 전환 전 확인

실사용 모드에서 Codex/CLI 실행 여부를 확인하고, 실행 중이면 경고 스타일로 재시작 안내와 대상 계정, 작업 완료·CLI 직접 종료 안내를 표시한다. 버튼은 기본 선택인 취소와 명시적인 계정 전환 및 재시작이다. 종료 상태에서는 계정 전환 및 열기로 안내한다. 상태 확인에 실패하면 진행하지 않는다. 같은 계정 선택과 복구 대기 중 전환도 차단한다. 데모 모드는 실제 프로세스를 조회하지 않는다. 빌드와 합성 테스트로 검증했으며 실사용 모달 클릭 검증은 사용자 테스트로 남긴다.

확인 문구 미리보기: `--render-preview --confirmation-preview --language=en`은 실행 중 상태, 여기에 `--codex-closed`를 추가하면 종료 상태를 그린다. 실제 NSAlert와 동일한 생성 함수를 사용해 문구와 버튼을 가져오지만, 시스템 모달의 픽셀 단위 캡처는 아니다. `--render-preview --product-preview --quit-blocked-preview --language=en`은 종료 거부 오류 패널을 그린다. 모두 가상 상태이며 프로세스 조회·모달 실행·계정 전환을 하지 않는다.
