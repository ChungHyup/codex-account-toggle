# Codex Switch UI / UX

## 컨셉: 조용하고 선명한 계정 스위처

계정 선택이라는 한 가지 행동에 집중하는 macOS 메뉴바 유틸리티. 따뜻한 중성 배경, 얇은 경계선, 절제된 청록색으로 현재 상태와 다음 행동을 빠르게 읽을 수 있게 한다. 사진이나 장식용 일러스트 대신 시스템 아이콘과 이름 첫 글자를 사용한다.

## 기존 화면의 문제와 개선

- 현재 계정이 disabled 버튼으로 표시되어 흐려짐 → 명도 저하 없는 독립 카드와 체크 표시로 강조.
- 시나리오 설정이 계정보다 먼저 보임 → 하단 데모 안내에서 필요할 때만 펼침.
- 모든 계정의 같은 아이콘/색상 → 안정된 계정별 색상과 이름 첫 글자로 구분.
- 이름 변경이 우클릭에 숨겨짐 → 각 계정의 가시적인 더보기 메뉴.
- 성공/오류가 일반 안내와 같은 회색 텍스트 → 상태 아이콘, 문구, 배경 색상을 함께 사용.
- 긴 안내문과 과도한 세로 여백 → 중복 문구를 줄이고 기본 높이를 484pt로 조정.

## 구조와 상호작용

헤더 → 현재 계정 → 다른 계정 → 필요한 상태 메시지 → 데모 안내 → 보조 도구 순서. 계정의 넓은 본문 영역을 클릭하면 전환하며, 더보기 버튼은 별도 액션이다. 현재 계정에서도 이름을 바꿀 수 있다. 전환 중에는 계정 선택과 관리 동작을 잠근다. 실제 전환 경로의 확인 절차는 유지한다.

380pt 폭, 20pt 바깥 여백, 8~20pt 간격, 13~16pt 카드 모서리. 본문은 시스템 폰트, 브랜드만 rounded 스타일. 주요 계정명 20pt, 일반 계정명 13pt, 이메일/보조 정보 11~12pt. 다크 모드는 시스템 외관을 따르며 청록색 밝기를 높인다.

아이콘 버튼에 접근성 이름과 도움말 제공. 상태는 색상에만 의존하지 않고 문구/아이콘 병기. 긴 계정명·이메일은 한 줄 생략하며 현재 계정의 전체 값은 도움말로 확인한다. 계정 수가 많아지면 목록만 스크롤한다.

## 검증 범위

실제 SwiftUI/AppKit 뷰를 가짜 계정으로 오프스크린 렌더링하여 라이트/다크, 오류 안내, 펼친 데모 설정의 레이아웃을 확인한다. 실제 로그인, 계정 전환, Codex 종료 테스트는 금지한다. UI 자동 클릭/VoiceOver 전체 탐색 검증은 아직 수행하지 않았다.
