Your accounts. One menu. Now for Claude too.

**Codex Account Toggle is now Pinch Hitter.** When one account runs out, send in a pinch hitter: the same menu-bar app now switches Claude desktop and terminal Claude Code accounts as well as Codex.

### Download & install
- **Pinch-Hitter-0.3.0-beta.1-universal.dmg**: macOS 13+, Apple Silicon and Intel.
- Open the DMG and drag Pinch Hitter to Applications. `SHA256SUMS.txt` contains the checksum.
- **Upgrading from Codex Account Toggle:** quit it from the menu bar first, then move it to the Trash. Saved accounts carry over, and settings (including live mode) are copied on first launch.

### New
- **Claude desktop accounts:** keep several Claude desktop accounts signed in and switch with a click, with no sign-out. Claude quits gracefully and reopens; it is never force-quit.
- **Terminal Claude Code accounts:** one config folder per account and a small `claude` shim; switching is instant for new terminal sessions. The app never edits your shell files.
- **Claude usage:** 5-hour and weekly allowance left for every Claude account, read from Claude's own local records. When a limit is hit, the exact time it lifts is shown.
- **Codex credit mode:** when the weekly allowance runs out and Codex continues on credits, the menu bar shows an orange $ with the remaining share of a business seat's monthly limit or a personal balance (850, 2.8K). It blinks only while credits are actually being spent.
- New name, new bundle identifier (`com.chunghyup.pinch-hitter`), new repository URL (the old one redirects).

### Fixed
- Live Codex reads after the ChatGPT app moved its bundled CLI (2026-09-27).
- A blocked 0% that stayed after the weekly allowance reset.
- The panel rolling back from the live credit display to an older weekly reading.
- Leftover Codex helper processes blocking a switch.

### Verification & limits
- 100 synthetic tests passed; macOS CI passed; universal build and mounted-DMG signature, icon, version, and architecture checks passed. See `docs/release-review-0.3.0.md`.
- **Ad-hoc signed, NOT Developer ID signed or notarized.** macOS blocks it on first launch; see the README for the one-time approval. No auto-updater. Intel hardware QA is pending.
- Claude's 5-hour reset time is an estimate; set the weekly reset once per account from Claude's Settings → Usage (right-click the account).
