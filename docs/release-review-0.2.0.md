# 0.2.0 beta release review

Reviewed 2026-09-14, starting from owner-tested upstream commit `69caefb`. Scope: changed application, usage transport, temporary-home onboarding, session attribution, saved-profile removal, tests, branding and packaging. The owner reports real-account QA; this review did not repeat it or inspect production credentials.

## Findings addressed

- Historical quota before the first identity observation could be assigned to the wrong account. Removed that inference and filter cached readings using the corrected attribution rule.
- Saved-profile deletion did not validate an ID before constructing a path. Added the same 64-hex identifier restriction used by credential reads, with a traversal regression case.
- Out-of-range JSON durations could trap during conversion to `Int`. Reject nonfinite, fractional or unrepresentable durations, with a regression case.
- Offscreen rendering could consult or mutate the persisted live-mode setting. Preview initialization now bypasses that setting entirely.
- Temporary-home login relied on the CLI default credential backend. The temporary configuration now explicitly selects file storage; the fake login verifies it.
- Account switching could begin during an in-flight usage read or onboarding. Added guards; live refresh also skips onboarding.
- Public-facing docs still described the new usage integration as disconnected. Rewrote the current behavior and separated product setup from development QA.

## Release decision

Suitable for an explicitly labeled **QA prerelease**, after automated tests, universal compilation, bundle verification and DMG integrity checks pass. This is not an unrestricted production/security certification.

Remaining limits: ad-hoc signature without Developer ID/notarization; no Intel hardware run in this review; no Windows binary; no auto-update; file-based authentication only; plaintext private credential copies; unobserved external account changes can limit local-history attribution; real work interruption and account validity must be verified by the owner. Do not provoke failures on production credentials.

The logo is original vector geometry generated by `scripts/make-icon.swift`. README screenshots are freshly rendered synthetic fixtures. No competitor artwork or credential fixture is shipped. Source and DMG remain in the owner's private repository until a later public-visibility request.

## Verification recorded

61 synthetic tests passed. Universal arm64/x86_64 build succeeded. The DMG checksum verified, and the read-only mounted app passed codesign verification, icon byte comparison, architecture and version checks, and the Applications install-link check. The application was not launched from the mounted DMG.
